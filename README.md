# Space Digest 4.0 — система обработки новостей

Настольное приложение для Windows и macOS: сбор новостей с сайтов (RSS) и из Telegram,
ежедневная выгрузка для ChatGPT в один клик, сюжеты вместо дублей, фильтр мусора,
дедупликатор и недельная база. Ставится обычным установщиком и открывается двойным
щелчком — без терминалов, `pip install`, `.env`, двух серверов и портов.

**Ежедневная работа (4.0):** вкладка «Выгрузка» → «Подготовить для ChatGPT» → промпт уже
в буфере → «Открыть ChatGPT», вставить промпт и CSV → скачать DOCX: программа сама
заберёт его из «Загрузок» в папку выгрузки.

Ниже — история изменений по блокам: 3.0 (приложение), затем блоки 1–5 версии 4.0.

## Что изменилось по сравнению с «ВЕРСИЕЙ 2»

| Было | Стало |
|---|---|
| Два сервера (Flask :5001 + FastAPI :8000), два окна терминала | Одна программа, своё окно с меню |
| `login_telethon.py` в терминале | Вход в Telegram в **Настройки → Telegram**: телефон → код → (пароль 2FA) |
| `.env`, `tg_config.json`, `admin_config.json`, `custom_sources.json` | Всё в окне **Настройки** (Ctrl+, / ⌘,) |
| Ключ DeepL вводится на каждой странице | Один раз в **Настройки → Перевод** |
| «Используйте либо автосбор, либо кнопку — не оба сразу» | Автосбор и кнопка работают вместе (один клиент Telegram) |
| torch + sentence-transformers (~1,5 ГБ) | Та же модель в ONNX (~220 МБ, скачивается один раз) |
| Пароль открытым текстом в JSON | Хранится как хеш |
| Данные рядом с кодом | Папка пользователя (можно перенести, есть резервная копия ZIP) |

Формат выгрузок (CSV/XLSX/MD), недельная база, история и логика дедупликации — прежние.

## Окно «Настройки»

Начало работы · Общие · Источники сайтов · Telegram · Перевод · Дедупликатор ·
Данные · Пароль · О программе. Изменения сохраняются сразу. Открывается кнопкой
**⚙ Настройки** в шапке, через меню и сочетанием **Ctrl+,** (на Mac **⌘,**).

## Как получить установщики

Собрать установщик для Windows можно только на Windows, а для Mac — только на Mac.
Проще всего поручить это GitHub (бесплатно):

1. Создайте на github.com приватный репозиторий и загрузите в него содержимое этой папки
   (кнопка «Add file → Upload files», вместе с папками `.github`, `packaging`, `spacedigest`).
2. Вкладка **Actions** → **Build installers** → **Run workflow**.
3. Через ~10–15 минут внизу страницы запуска, в **Artifacts**, появятся:
   * `SpaceDigest-Windows` → `SpaceDigest-Setup-4.2.0.exe`
   * `SpaceDigest-macOS-AppleSilicon` → `.dmg` для Mac на M1–M4
   * `SpaceDigest-macOS-Intel` → `.dmg` для Mac на Intel

Собрать на своём компьютере (нужен Python 3.12 с python.org, один раз):

* **Windows:** установите [Inno Setup 6](https://jrsoftware.org/isdl.php), затем двойной щелчок по
  `packaging\build_windows.bat` → `dist\SpaceDigest-Setup-4.2.0.exe`.
* **macOS:** `bash packaging/build_macos.sh` → `dist/SpaceDigest-4.2.0-mac-arm64.dmg`.

## Установка у пользователя

**Windows.** Запустить `SpaceDigest-Setup-….exe` → Далее → Готово. Права администратора не нужны.
При первом запуске SmartScreen может показать «Windows защитила компьютер» (у программы
нет платной цифровой подписи): **Подробнее → Выполнить в любом случае**. Один раз.

**macOS.** Открыть `.dmg`, перетащить **Space Digest** в «Программы». Первый запуск:
macOS скажет, что разработчик не проверен — откройте **Системные настройки →
Конфиденциальность и безопасность → «Всё равно открыть»**. Один раз.
Если macOS пишет «программа повреждена» (так бывает с файлами, скачанными браузером
с GitHub), один раз выполните в Терминале:
`xattr -dr com.apple.quarantine "/Applications/Space Digest.app"`.
Программа собирается с бесплатной локальной подписью (ad-hoc) — для личного использования
этого достаточно. Обновления, скачанные самой программой, этих окон уже не вызывают.
(Убрать окно навсегда можно подписью Apple Developer ID — 99 $/год; сценарий сборки
уже умеет подписывать и нотаризовать, если добавить секреты `APPLE_*` в репозиторий.)

## Первый запуск

Откроется **Настройки → Начало работы**:
1. **Перенести данные из старой версии** — выберите папку «ВЕРСИЯ 2». Перенесутся история,
   недельная база, свои источники, пароль, ключи и вход в Telegram, все посты из `news.db`.
2. **Telegram** — если не переносили: API ID / API Hash с my.telegram.org и вход по коду.

## Где лежат данные

* Windows: `%APPDATA%\SpaceDigest`
* macOS: `~/Library/Application Support/SpaceDigest`

Внутри: `settings.json`, `jobs/ dedup/ tg/ uploads/` (история), `weeks/` (недельная база),
`telegram/news.db` и вход в Telegram, `models/` (нейросеть), `logs/app.log`.
При удалении программы данные остаются. Перенести папку (например, в OneDrive) —
**Настройки → Данные → Перенести…**.

## Ядро 4.0 (блок 1 — фундамент)

Работает внутри программы рядом с интерфейсом 3.0, сам интерфейс пока не меняется.

* **Единая база** `spacedigest.db` в папке данных: источники, все публикации (сайты и Telegram),
  очередь задач, расписание. Схема версионируется (`spacedigest/core/migrations/NNN_*.sql`),
  перед обновлением схемы делается резервная копия базы.
* **Полный текст из RSS**: сохраняются анонс (`description`) и полный текст (`content:encoded`)
  без обрезки (в 3.0 текст обрезался до 500 символов), `guid`, автор, дата.
  HTML-сущности раскодируются, хвосты «The post … appeared first on …» убираются.
* **Автосбор сайтов** раз в час, Telegram — по своему интервалу (оба настраиваются), условные
  запросы ETag/Last-Modified, «здоровье» каждого источника (последний успех, ошибка, неудачи подряд).
* **Перенос 3.0** при первом запуске: история выгрузок, недельная база, `news.db`, свои
  источники и каналы. Старые файлы не меняются, архив не затирает свежесобранный текст.
* Состояние ядра: `http://127.0.0.1:<порт>/api/core/status`.

Тесты: `python -m pytest -q tests` (запускаются и в облачной сборке перед созданием установщиков).

## Блок 2 — экран «Выгрузка» и ChatGPT в программе

Новая стартовая вкладка **📤 Выгрузка** — ежедневная работа в одном месте:

1. **Что выгружаем**: «С прошлой выгрузки» (всё, что собрано после предыдущей выгрузки, —
   ничего не теряется и не повторяется) или «За даты».
2. **📤 Подготовить для ChatGPT** — программа отбирает новости, убирает повторы (в том числе
   то, что уже было в выгрузках за последние N дней, — ручная «недельная база» больше не нужна),
   сохраняет CSV с полным текстом и промпт с подставленным периодом в отдельную папку
   и сразу копирует промпт в буфер обмена.
3. **Открыть ChatGPT** — отдельное окно программы (вход запоминается) или браузер — по настройке.
   Промпт вставляется Ctrl+V / ⌘V, CSV перетаскивается из открытой папки.
4. **Забрать DOCX** — программа находит свежий DOCX в «Загрузках» и кладёт его в папку выгрузки.
   История выгрузок — внизу экрана.

CSV: `ID; Дата публикации; Источник; Тип источника; Заголовок; Полный текст; Ссылка` (UTF-8 с BOM).
В промпте строка периода — переменная `{{ПЕРИОД}}`, её заменяет программа. Промпт, папка,
сверка с прошлыми выгрузками и окно ChatGPT настраиваются в «Настройки → Выгрузка и ChatGPT».

Telegram теперь собирается ядром (один клиент, расписание, «здоровье» каналов); вкладка
Telegram берёт посты из общей базы.

## Блок 3 — сюжеты и проверка выгрузки

* **Повторы больше не теряют факты.** Версии одного события с разных сайтов и каналов
  сводятся в одну строку CSV: полный текст основной версии (сайты важнее Telegram) +
  предложения других версий, которых в основной нет (`[Дополнительно: Источник] …`).
  Призывы подписаться, рекламные хвосты и подписи к фото не переносятся.
  Ссылки на остальные версии — в новом столбце «Другие источники»; «Ссылка» по-прежнему одна.
* **«Уже было»** — то, что выгружалось за последние N дней, в CSV не идёт; для этого порог
  близости строже на 0,04, чем для сведения версий (ошибка здесь стоит дороже).
* **Проверка выгрузки** на экране «Выгрузка»: вкладки «Строки CSV», «Сюжеты», «Уже было»,
  «Убрано». Ошибочно сведённую версию — «Отдельной строкой», нужное старое событие —
  «Вернуть в CSV», мусор — «Убрать». CSV пересобирается сразу; убранное не считается выгруженным.
* **Кэш векторов** нейросети в базе (`item_vectors`): каждая новость векторизуется один раз,
  сверка с прошлыми выгрузками не пересчитывает тысячи текстов. Старые векторы (60+ дней)
  удаляет ежедневное обслуживание.
* Схема базы v3 (`003_stories.sql`), прошлые выгрузки размечаются автоматически.

## Блок 4 — фильтр мусора

* **Стоп-слова** для всех источников: по умолчанию — реклама (метка `erid`, «на правах рекламы»),
  промокоды, розыгрыши.
* **«Только про космос»** для отдельных источников (ленты общего профиля): новость проходит,
  только если в ней есть космическое слово. Программа сама считает долю «не про космос» за 30 дней
  и рекомендует источники, где её больше 40 %; включить все рекомендованные — одна кнопка.
* Синтаксис слов: `ракет*` — все формы, `ESA` — целое слово, `магнитн* бур*` — фраза, `# …` — комментарий.
* **Ничего не удаляется**: отсеянное — во вкладке «Отфильтровано» с причиной, «Вернуть в CSV».
  В списке «Новости к выгрузке» отсеиваемое заранее помечено.
* **Подсказки из ваших действий**: если в «Убрано» одно и то же слово встретилось минимум
  в трёх новостях и почти не встречается в остальных, программа предложит сделать его стоп-словом
  (космические слова не предлагаются). Новое правило сразу чистит открытую выгрузку; подсказку можно скрыть.
* Настройки → «Фильтр мусора». Схема базы v4 (`004_filter.sql`).

## Блок 5 — обновления, сохранность данных, новый интерфейс

* **Обновления**: Настройки → О программе → репозиторий GitHub (owner/name) →
  «Проверить обновления» → «Скачать и установить». Установщик под свою систему
  (.exe; .dmg для Apple Silicon / Intel) скачивается в «Загрузки» и запускается.
  Данные лежат отдельно от программы и не затрагиваются. При запуске программа сама
  проверяет новую версию (не чаще раза в 6 часов) и ставит зелёную точку на «Настройки».
  Релиз публикуется автоматически, если отправить тег `vX.Y.Z` (GitHub Actions уже настроен).
* **Резервная копия** — согласованный снимок базы (SQLite backup API, даже во время сбора),
  настройки, недельная база, история. Без входа в Telegram и ChatGPT.
  **Восстановление** — Настройки → Данные → «Восстановить из копии»: применяется при
  перезапуске, прежние данные откладываются в «_до_восстановления_<дата>», вход в Telegram сохраняется.
* **DOCX забирается сам**: после «Открыть ChatGPT» программа каждые 5 секунд смотрит
  «Загрузки» и папку выгрузки (до 45 минут); недокачанные файлы пропускаются.
* **Интерфейс: светлое бело-синее оформление** с приёмами Aceternity UI и Magic UI
  (перенесены на CSS/JS, без React и сборки):
  * фон — Dot Pattern и Animated Grid Pattern (вспыхивающие клетки), синие Background Beams, мягкая Aurora;
  * карточки — Magic Card / Glowing Effect (пятно света и синяя кромка за курсором);
  * вкладки и переключатели — скользящая подсветка (Tabs / Card Hover Effect);
  * кнопки — Shimmer Button с бегущей кромкой (главные действия), Shiny Button (блик),
    Ripple (волна от нажатия), Interactive Hover Button (стрелка у «Открыть ChatGPT»);
  * готовая выгрузка — Border Beam по рамке, Meteors, Animated Shiny Text в заголовке;
  * «Начало работы» — Animated Beam: Сайты + Telegram → Space Digest → ChatGPT → DOCX;
  * пустые экраны — Orbiting Circles; DOCX забран — Confetti;
  * Aurora Text в названии, Number Ticker в счётчиках, Blur Fade при появлении, Text Generate в заголовках,
    Scroll Progress сверху.
  Шрифты Inter и JetBrains Mono с кириллицей — локально, иконки — SVG в стиле Tabler.
  Анимации выключаются в Настройки → Общие и при системной настройке «уменьшить движение».

## Блок 6 — полный текст, утренняя выгрузка, подбор порога, обзор, тёмная тема

* **Полный текст статей.** Если лента сайта даёт только анонс (короче 600 символов — настраивается),
  программа после сбора открывает страницу статьи и берёт основной текст (trafilatura: без меню,
  рекламы и комментариев). Полный текст не затирается следующим сбором; если статья в ленте
  изменилась — берётся заново. Кнопка «Дотянуть полные тексты» — для последних 7 дней.
  Заодно чинятся «кракозябры» (UTF-8, прочитанный как CP1252: «planetâ€™s» → «planet’s») —
  в архиве так испорчено 237 новостей Universe Today; при выгрузке они уже исправляются.
* **Утренняя выгрузка** (Настройки → Выгрузка и ChatGPT): в заданное время по Москве программа
  собирает сайты и Telegram, дожидается полных текстов, готовит CSV и промпт «с прошлой выгрузки»
  и показывает системное уведомление. Экран «Выгрузка» сам открывает её. Пропущенное утро
  выполняется при запуске (но не дважды). «Запускать вместе с компьютером» — программа стартует
  свёрнутой (Windows: автозапуск пользователя, macOS: LaunchAgent).
* **Подбор порога дедупликации** (Настройки → Дедупликатор): ~20 пар свежих новостей «на грани»,
  ответы «одно событие / разные» (клавиши 1/2/3), порог с наименьшим числом ошибок — одной кнопкой.
  Ошибочное объединение считается в 1,5 раза дороже пропущенного повтора. Ответы копятся.
* **Обзор** — новая стартовая вкладка: что готово сейчас, публикации за 14 дней, источники
  с ошибками и «замолчавшие», утренняя выгрузка, последние выгрузки, активные источники, качество данных.
* **Тёмная тема** — Настройки → Общие → Тема: светлая, тёмная или как в системе.
* Страницы «Сайты», «Telegram», «Дедупликатор» — без эмодзи, в общем стиле; новая иконка программы.
* Схема базы v7 (`005_fulltext.sql`, `006_daily.sql`, `007_calibration.sql`).

## Версия 4.1 — дайджест СЛК и производительность

**Вкладка «СЛК»** — дайджест по ракетам-носителям сверхлёгкого класса (бывший отдельный «Парсер СЛК»).
* Общая база и общий сбор: к источникам Space Digest добавлены 43 источника СЛК (сайты компаний из перечня ТЗ,
  РБК, КП, Роскосмос, Хабр…) и Telegram-канал Space Energy. Список — `spacedigest/slk_sources.py`.
  Источники СЛК идут только в выгрузку СЛК; выгрузка СЛК читает ещё и все общие источники.
* Окно выгрузки: 14 новых дней + 7 дней перекрытия с прошлым поиском (Настройки → Дайджест СЛК).
  То, что уже было в прошлой выгрузке СЛК, остаётся в CSV с отметкой «Было в прошлом дайджесте».
* Мягкий предфильтр (`services/slk.py`): сайты компаний из перечня — целиком; остальное — по названиям РН и
  компаний или «ракетным» словам; у изданий общего профиля — ещё и однозначно космическое слово; военная
  тематика без названий из перечня — отсев. Отсеянное видно во вкладке «Отфильтровано».
* Свой промпт (`prompts/slk_default.txt`): проверка дат поиском, повторы, приложения «Требует ручной
  проверки даты» и «Было в прошлом дайджесте». В CSV добавлены столбцы «Дата проверена» и «Было в прошлом дайджесте».
* Перенос из старого парсера СЛК: Настройки → Дайджест СЛК → «Найти автоматически» (свои источники и
  исправленные адреса; ключи Gemini не нужны).

**Старые новости больше не выдаются за свежие.** Сайты без RSS (`connectors/html_page.py`) разбираются по
карточкам. Карточка без даты раньше проходила любой фильтр — так в дайджест попадал архив Space Energy
2023–2025 годов. Теперь у каждой новости есть `date_status`: дата из ленты, из карточки (`card`), со страницы
статьи (`page`, htmldate), не подтверждена (`none`) или архив сайта при первом сборе (`baseline` — в выгрузки
не идёт). Даты карточек и неподтверждённые даты сверяются со страницей статьи автоматически.

**Окно ChatGPT больше не тормозит.** Все окна программы рисует один графический процесс WebView2: главное
окно постоянно анимировало фон и кнопки, а шапка размывала анимированный фон под собой каждый кадр. Теперь
размытие убрано, бесконечные перерисовки заменены разовыми, а когда окно программы не в фокусе (вы работаете
в ChatGPT) или свёрнуто, все анимации стоят на паузе. Поиск DOCX в «Загрузках» стал дешевле.

## Версия 4.2 — дедупликатор: предохранители и «один сюжет»

Замер на реальных выгрузках ноября 2026 (`bench/`, задача Actions «Dedup benchmark») показал: текущая
склейка (MiniLM, порог 0,82) точная, но пропускает большинство повторов, написанных разными словами; более
крупные модели и векторные базы этого не исправляют — все модели путают «тот же факт» и «соседние части
одного события» (анонс пуска и сама авария). Поэтому:

* **Склейка остаётся точной** и получила предохранители (Настройки → Дедупликатор): склеиваются только
  новости в окне 4 дней; разные номера в заголовках («миссия 98» / «99», «Ship 41» / «42») — не склеиваются.
* **Новый уровень «один сюжет»** — столбец «Связанные строки» в CSV обеих выгрузок: номера строк того же
  сюжета. Отдельная модель multilingual-e5-small (ONNX int8, ~120 МБ, `spacedigest/story_model.py`) встроена
  в установщик; строки не склеиваются — ChatGPT по промпту решает, дубликат это или разные части события.
* В установщике — самопроверка моделей (`SpaceDigest --selftest`), она выполняется при каждой сборке в CI.
* Замер: `bench/data/*.csv` — выгрузки, `bench/labels_*.json` — разметка пар (same / related / diff),
  результаты — `bench/results/result.md`.

## Для разработчика

```bash
pip install -r requirements.txt
python main.py            # окно
python main.py --browser  # в браузере
python main.py --server --port 5001 --data ./dev-data
```

Ядро 4.0: `spacedigest/core/` (база, миграции, очередь задач, планировщик, `runtime.Core`),
`domain/` (модели, нормализация текста и ссылок), `connectors/` (RSS, Telegram),
`services/` (источники, приём в базу, сбор, перенос 3.0, выгрузка, сюжеты, кэш векторов, фильтр, полный текст, подбор порога, обзор), `tests/`.

Структура 3.0: `main.py` — лаунчер (окно pywebview, меню, диалоги сохранения);
`spacedigest/webapp.py` — Flask и API; `telegram_service.py` — Telethon внутри программы;
`settings.py` — настройки; `migrate.py` — перенос из старой версии;
`fetcher.py`, `deduplicator.py`, `translator.py`, `exporters.py` — прежняя логика;
`packaging/` — PyInstaller, Inno Setup, DMG; `.github/workflows/build.yml` — сборка в облаке.
