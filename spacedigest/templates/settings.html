Выгрузка и ChatGPT

Как готовится ежедневный файл для ChatGPT: что в него попадает, куда он сохраняется и каким промптом обрабатывается.

Утренняя выгрузка
Готовить выгрузку каждое утро В указанное время программа соберёт сайты и Telegram, дотянет полные тексты, уберёт повторы и подготовит CSV с промптом «с прошлой выгрузки». Придёт уведомление — останется открыть ChatGPT. Если компьютер был выключен, выгрузка подготовится при запуске программы.
Время, по Москве …
Уведомление, когда готово
Запускать вместе с компьютером Программа стартует свёрнутой при входе в систему — к утру выгрузка будет готова без вашего участия.
Проверить прямо сейчас Соберёт новости и подготовит выгрузку так же, как утром.
Убирать повторы перед выгрузкой Одно событие с разных сайтов и каналов — одна строка файла: полный текст основной версии и новые факты из остальных. ChatGPT не тратит силы на дубли и не теряет подробности.
Сверять с прошлыми выгрузками, дней Новость о событии, уже попавшем в выгрузку за эти дни, не повторится. 0 — не сверять. Заменяет ручную «недельную базу».
Папка выгрузок Пусто — «Документы / Space Digest / Выгрузки». Для каждой выгрузки создаётся своя папка: CSV, промпт и готовый DOCX.
ChatGPT
Где открывать «В программе» — отдельное окно рядом, вход запоминается. Если войти не получается (например, вход через Google), выберите «В браузере».
Адрес чата Можно указать ссылку на свой проект или GPT в ChatGPT.
Промпт
Текст промпта … Вместо {{ПЕРИОД}} программа подставит даты новостей из выгрузки (например, «2026-11-13 - 2026-11-14»). Больше ничего менять перед отправкой не нужно.

Дайджест СЛК

Выгрузка по ракетам-носителям сверхлёгкого класса — вкладка «СЛК». База и сбор общие с основным дайджестом: к вашим сайтам и каналам добавлены сайты компаний из перечня ТЗ и издания общего профиля.

Период
Новые дни Сколько последних дней выгрузка считает новыми. Обычно — две недели.
Перекрытие с прошлым поиском, дней Ещё столько дней до новых: подхватывает новости, которые сайты опубликовали с опозданием. То, что уже было в прошлой выгрузке СЛК, придёт в CSV с отметкой — ChatGPT не повторит его без нового факта.
Сводить версии одного события Одно событие из нескольких источников — одна строка CSV с новыми фактами остальных.
Папка выгрузок СЛК Пусто — «Документы / Space Digest / Выгрузки СЛК».
Источники СЛК
Сайты компаний и издания У сайтов без RSS разбирается страница новостей. Если у новости на сайте нет даты, программа берёт её со страницы статьи; не нашла — в CSV пометка «дата не подтверждена», и ChatGPT проверяет её поиском. Всё, что сайт показал при самом первом сборе без дат, считается архивом и в выгрузку не идёт.
Загрузка…
Перенести из старого «Парсера СЛК» Свои источники и исправленные адреса. Ключи Gemini и старые промпты не нужны — не переносятся.
Мягкий предфильтр
Убирать явно лишнее перед ChatGPT Сайты компаний из перечня проходят целиком. Остальное — если есть название РН или компании из перечня либо «ракетное» слово (пуск, двигатель, космодром…); у изданий общего профиля — ещё и космическое слово. Военная тематика без названий из перечня отсеивается. Всё отсеянное видно во вкладке «Отфильтровано».
Названия РН и компаний … Новость с таким названием проходит всегда. Синтаксис как в фильтре мусора: Kuaizhou* — все формы, РН — только целое слово.
Ракетные слова … Без хотя бы одного из них новость космического издания или канала отсеивается.
Военная тематика … Отсеивается, если в новости нет названий из перечня.
Промпт СЛК
Текст промпта … Программа подставит {{ПЕРИОД}} — всё окно выгрузки, {{НОВЫЙ_ПЕРИОД}} — новые дни, {{ПЕРЕКРЫТИЕ}} — дни перекрытия с прошлым поиском. Встроенный промпт проверяет даты поиском и не повторяет новости из прошлого дайджеста.

Фильтр мусора

Реклама и новости не про космос не попадают в файл для ChatGPT. Ничего не удаляется: отсеянное видно во вкладке «Отфильтровано» на экране выгрузки и возвращается одной кнопкой.

Фильтровать перед выгрузкой Выключите, если хотите отдавать ChatGPT всё подряд.
«Только про космос» по источникам
Для лент общего профиля Новость такого источника попадёт в выгрузку, только если в ней есть космическое слово (список ниже). Доля «не про космос» — за последние 30 дней. Рекомендуем — где таких больше 40 %.
Загрузка…
Слова
Как писать ракет* — слово и все его формы · ESA — только целое слово · магнитн* бур* — фраза · строка с «# » в начале — комментарий. Регистр не важен.
Стоп-слова — для всех источников … Новость с таким словом не попадёт в выгрузку. По умолчанию — реклама (метка erid), промокоды, розыгрыши.
Космические слова … Нужны только источникам с «только про космос»: если ни одного слова нет — новость отсеивается. Если фильтр отсеял нужную новость — добавьте сюда слово из неё.

Источники сайтов

Переключатель — «отмечен по умолчанию» на странице «Сайты». Встроенные источники можно выключить, свои — добавить, изменить и удалить. Кнопка «Проверить» проверяет, отдаёт ли лента новости.

Перевод

Используется на всех страницах — ключ больше не нужно вводить каждый раз.

Переводить на русский по умолчанию Тумблер «Переводить» на страницах будет включён сразу.
Сервис перевода Google — бесплатно, без ключа. DeepL — выше качество, нужен ключ (бесплатный тариф ≈ 500 000 символов в месяц).

Окно склейки, дней Склеивать только новости, между которыми не больше стольких дней: похожие события (еженедельные пуски) не сольются в одно. 0 — без окна.
